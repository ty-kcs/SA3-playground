# Stable Audio 3 — Colab helpers

Python helpers for trying [Stable Audio 3](https://github.com/Stability-AI/stable-audio-3) in Colab.

**Repo:** [github.com/ty-kcs/SA3-playground](https://github.com/ty-kcs/SA3-playground)

The notebook (`sa3_playground.ipynb`) is shared via Google Drive only — not in this repo. Open it in Colab and run top-to-bottom (setup uses `uv sync` from `stable-audio-3`’s `uv.lock`).

Colab dependency experiments (`requirements.txt`, `simulate_colab.sh`, etc.) stay local — see `.gitignore`.
